# Web Simple

Blog estático para la actividad extraordinaria de Desarrollo de Aplicaciones en Red.

## Tecnologías
- HTML5: estructura principal.
- CSS3: presentación y diseño adaptable.
- JavaScript: menú móvil y demostración de eventos/DOM.

## Cómo abrirlo
Abrir `index.html` directamente en un navegador.

## Publicación
La carpeta puede subirse tal cual a GitHub y publicarse con GitHub Pages.
