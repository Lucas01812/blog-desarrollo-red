HTML5

La estructura de una página web

HTML es un lenguaje de marcado: su misión principal no es decidir colores ni animaciones, sino describir y organizar el contenido que interpreta el navegador.

Semántica

HTML5 añadió etiquetas como <header>, <nav>, <section>, <article> y <footer>. Con ellas el documento expresa mejor qué función cumple cada bloque.

<article>
  <h2>Título de entrada</h2>
  <p>Resumen del contenido...</p>
</article>

Formularios

Otra mejora importante es la ampliación de controles de entrada. Tipos como email, url o tel ayudan a describir mejor los datos solicitados.

En este blog, HTML5 forma el esqueleto de todas las páginas y permite que el contenido siga siendo legible incluso si se desactiva CSS o JavaScript.
