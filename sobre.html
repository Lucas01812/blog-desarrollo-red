Sobre el blog

Este sitio se ha construido como parte de la actividad extraordinaria de Desarrollo de Aplicaciones en Red. HTML5 es la tecnología principal para estructurar cada página; CSS3 define el diseño y JavaScript añade una interacción pequeña y comprensible en el menú y en el botón de ejemplo.

Objetivos cumplidos

  • Portada con el resumen de tres entradas.
  • Navegación entre portada, información y detalle de cada entrada.
  • Diseño adaptable a pantallas pequeñas.
  • Código separado en HTML, CSS y JavaScript para facilitar su mantenimiento.
