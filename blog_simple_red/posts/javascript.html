JavaScript

Interacción en el navegador

JavaScript añade comportamiento a una página web. Puede responder a eventos y modificar el DOM, la estructura en forma de árbol que el navegador crea al cargar el documento.

Un evento sencillo

El siguiente botón cambia el texto mediante un evento click.

Todavía no has pulsado el botón.

boton.addEventListener('click', () => {
  resultado.textContent = 'JavaScript ha respondido al evento';
});

DOM y mantenimiento

El código JavaScript del blog se mantiene en un archivo externo. El script busca elementos del documento y modifica únicamente los necesarios. También controla el menú en pantallas pequeñas.

La idea es mostrar que no hace falta un framework complejo para incorporar una interacción útil en un proyecto pequeño.
