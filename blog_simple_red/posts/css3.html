CSS3

Convertir estructura en diseño

CSS permite separar el contenido de su presentación. Esto hace que un mismo documento HTML pueda cambiar de apariencia sin modificar su estructura.

Selectores

Las reglas CSS se aplican mediante selectores. Se puede seleccionar una etiqueta, una clase o un identificador.

.tarjeta {
  border-radius: 16px;
  padding: 1.2rem;
}
.tarjeta:hover {
  transform: translateY(-3px);
}

CSS3

CSS3 amplió las posibilidades visuales con transparencias, bordes redondeados, sombras, gradientes, transformaciones y transiciones. En este proyecto se usan varias de ellas de forma moderada para obtener un diseño atractivo sin complicar el código.

La hoja estilos.css es externa y compartida por todas las páginas, lo que evita repetir reglas y facilita el mantenimiento.
